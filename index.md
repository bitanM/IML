# Introduction to Machine Learning Lecture Notes

**Instructor:** Dr. Anirban Sen  
**Institution:** Ashoka University  
**Course:** Introduction to Machine Learning (IML)

## Welcome

This website contains comprehensive lecture notes for the Introduction to Machine Learning course. The notes cover the mathematical foundations and practical algorithms for machine learning, with detailed derivations, geometric intuition, and extensive problem sets.

| Lecture | Topic | Key Concepts |
|---------|-------|--------------|
| **Lecture 2** | [Convex Functions & Optimization](/lectures/Lecture_2_Convex_Functions_Optimization/) | Convexity definitions, Hessian, zᵀHz test, optimization guarantees |
| **Lecture 3-5** | [Linear Regression (Probabilistic View)](/lectures/Lecture_3_5_Linear_Regression_Probabilistic/) | Gaussian noise model, MLE ↔ Least Squares, Normal Equations, assumptions |

| **Lecture 11** | [Support Vector Machines](/lectures/Lecture_11_SVM_Support_Vector_Machines/) | Hard/Soft margin, hinge loss, regularization, dual formulation |
