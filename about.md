# About This Project

## Course Information

**Course:** Introduction to Machine Learning (IML)  
**Instructor:** Dr. Anirban Sen  
**Institution:** Ashoka University  
**Department:** Computer Science / Data Science  
**Semester:** Fall 2026  

## Website Purpose

This website serves as a comprehensive, searchable, and navigable reference for the IML course lecture notes. It was created to:

1. **Consolidate** all lecture materials in one accessible location
2. **Enable easy navigation** between related topics across lectures
3. **Provide full-text search** across all notes
4. **Support self-paced learning** with problem sets and worked examples
5. **Serve as a long-term reference** for students and practitioners

## Content Sources

The notes are based on lectures delivered by Dr. Anirban Sen at Ashoka University during Fall 2026. The material covers:

- **Convex Optimization** (Lecture 2) - Foundations for understanding optimization in ML
- **Linear Regression** (Lectures 3-5) - Probabilistic perspective, MLE, least squares
- **Linear Classification** (Lectures 6-8) - Discriminant functions, generative models, MLE
- **Logistic Regression** (Lecture 9) - Discriminative approach to classification
- **Support Vector Machines** (Lecture 11) - Large-margin classification
- **Fisher's LDA Assignment** - Practical application with historical context

## Navigation Design

The navigation follows the pedagogical progression of the course:

```
Convex Optimization → Linear Regression → Linear Classification → Logistic Regression → SVM
                                                      ↓
                                            Fisher's LDA (Application)
```

Each lecture note includes:
- Complete mathematical derivations
- Geometric intuition with diagrams
- Problem sets with varying difficulty
- Worked numerical examples
- Key takeaways summary

## Fisher's LDA Assignment

The Fisher's LDA section contains:
- **Assignment.md** - Complete assignment specification with all 8 tasks, rubrics, and viva guidelines
- **Mathematics_Sheet.md** - Concise mathematical reference (summary)
- **Mathematics_Sheet_Detailed.md** - Step-by-step derivations from first principles

This assignment reconstructs Fisher's 1936 analysis of the Iris dataset using only NumPy linear algebra, providing both historical context and practical implementation experience.
